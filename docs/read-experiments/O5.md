# O5: bounded encrypted-history reuse feasibility

Status: FEASIBILITY_DEMONSTRATED for the immutable synthetic fixture; not production-ready. Final base source is `13a43c8662b632be1dadb4110363f88a7f1cf8c1`. The probe implementation, measurement overlay and copied binaries are retained in the local evidence bundle; they are not part of the runtime source in this branch. [Full results](results.md) and [ledger](ledger.md) define the acceptance limits.

The measured hot-query fixture resolves warm postings but still starts 16 physical canonical scans. The probe caches fully validated, fully consumed encrypted spans keyed by exact database opening, route, incarnation and interval. Every hit still performs exact filtering, AEAD, page admission and cursor assembly. Empty or partially consumed coverage is not admitted.

The prototype reserves 2 MiB from the existing backend-cache allowance, with 64 KiB permanently charged for the preallocated map, at most 256 entries, 64 KiB reservations for fills and opportunistic bypass under pressure. It copies backend slices immediately into bounded owned storage before retaining them, then packs immutable encrypted owners with a reservation that survives map eviction while readers hold Bytes. Conservative charges include metadata and transient copies. Cancellation and oversized capture drop capacity before releasing reservations.

Final regressions exercise cancelled fill reservation release, retained-reader reservation after eviction, distinct physical database/incarnation keys, compact backing ownership, wrong-key authentication refusal and oversized bypass. Warm queries produce 16 cache hits and zero physical scans each with the same 16-record complete result; measured residency is 109,376 reserved bytes including the map. Cache-off uses the identical binary and memory carve-out.

Five paired System blocks show hot median 403 → 168 µs for cache-off/on; original is 368 µs. The paired on/off median ratio is 0.417 [0.411, 0.424]. Three offered-load blocks also favor the cache for repeated history. These are screening results, not the preregistered larger acceptance campaign.

Production retirement/retention and descriptor lifecycle integration, per-tenant admission, coalesced identical fills and high-cardinality/rotating-range pressure are incomplete. Sufficient cold-tail, slow-reader/tenant interference, lifecycle and production-allocator campaigns remain. The initial probe screen is retained but superseded because early capture could pin a larger backend allocation; the final screen uses immediate compaction. No warm-query result grants production cache acceptance.
