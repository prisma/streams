# O3: retained durable ring coverage

Experimental; performance and correctness acceptance pending. Control: O1 (`142fa1607570b87f07b04c4cd75df12373b7d4b5`).

Each ring read now validates every inspected offset for density, validates the frame even when its routing key does not match, and proves only the interval actually inspected. A private witness binds that interval to the segment identity and a weak reference to the physical database opening. The weak reference prevents address reuse from turning an old proof into a new owner's proof. Requested bounds must be below the published durable frontier. No proof is issued for gaps, invalid rows, or an applied read.

The application can avoid its redundant remote absorption-marker lookup for this proof. Database scans still read the remote absorption boundary and layout together. Visibility, authentication, pagination and outer ownership checks are unchanged. Ring endpoint metadata by itself is no longer sufficient.

The new held-marker regression scopes the hold to the actual read future after handle warming. It checks a complete keyed hit, a byte-limited match-free prefix, wrong identity/owner rejection, applied visibility as a negative control, and a missing middle ring row forcing canonical fallback and marker revalidation. Existing corrupted-ring, trim, lifecycle and exact-progress tests remain gates.

The extra state is one weak reference and interval metadata per ring page, plus one durable-frontier check. Benchmark these costs against the removed marker lookup; do not infer a cloud GET or latency win from source inspection.

The final origin check also binds each handle to its database opening. A different engine cannot manufacture a new witness from an old handle's ring. The regression exercises both keyed and unfiltered cross-owner calls. This adds one weak pointer per resident handle; ordinary proof comparison uses pointers without a temporary weak-reference increment.
